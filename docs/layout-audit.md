# 论文印刷格式核查记录

核查日期：2026-10-16。

依据：[西南财经大学关于研究生学位论文形式与格式的基本要求](https://graduate.swufe.edu.cn/info/1036/2142.htm)网页正文“十三、论文打印及装订”中的五项印刷格式要求。网页发布于 2018-11-13，正文标注 2007 年 3 月修订，另附 2019 年 5 月调整的 Word 文件。本次对照范围为网页列出的五项印刷参数，不包含论文内容、附件封面样式及学院补充要求的全面审核。

对象：调整后的 `main.pdf`，共 17 页，TeX Live 2026 / SJTUTeX 2.3.1 编译。文件 SHA-256 为 `a8f2108c363325cea1c123100cac53e2703bf5f8b489062deb969386359dbd1f`。后续改动字体或布局后，需要重新核查。

**结果：原核查中发现的版心、行列数、标题、图表及页眉页脚参数差异已修正。连续中文测试页实测为每页 30 行、每行 33 字；九项编译回归检查通过。**

## 调整后逐项对照

字体大小按 PDF 点（1/72 英寸，即 LaTeX 的 `bp`）计量；TeX 的 `pt` 为 1/72.27 英寸，计算时已换算。测量结合 PDF 字体与文字坐标、页面渲染和实际生效的 TeX 参数。

| 项目 | 调整前 | 调整后及验证结果 |
| --- | --- | --- |
| 纸张 | A4 | 所有页面保持 A4，约 210 × 297 mm |
| 中文正文 | 小四号 FandolSong | 固定为小四号 FandolSong（12 点），西文为 Times New Roman |
| 正文版心 | 上约 2.53、下 4.97、左 3.00、右 2.50 cm | 上 3.90、下 3.40、左 3.45、右 3.45 cm；宽 14.10、高 22.40 cm |
| 行数、列数 | 约 23 行、36.6 个全角字宽 | 独立测试中，前两个完整正文页各 30 行，每行 33 个汉字；第三页剩余 5 行 |

| 页眉、页脚位置 | 未按规定距离校准 | 页眉框顶边距纸顶 2.80 cm，页码基线距纸底 2.50 cm；页眉线宽与正文版心同为 14.10 cm |

FandolSong、FandolHei 分别属于宋体、黑体类别，随 TeX Live 提供。模板固定使用 Fandol 字体集，避免操作系统自动选择不同字体。内封保留华文中宋；章标题使用单独的小标宋，不将两种字体混同。

## 参数实现与测量口径

所有正文版心、行距、标题、图表和页眉页脚设置集中在 [`swufe-layout.tex`](../swufe-layout.tex)，由 [`setup.tex`](../setup.tex) 加载。移除了 `main.tex` 中重复的排版设置，避免再次覆盖有效值。

### 行列数与 1.37 倍率

正文高为 22.4 cm，将其分为 30 个行位，每个行位约为 21.16535 PDF 点。以该值除以 1.37 得到单倍基础行距，约为 15.44916 点；随后应用 `\setstretch{1.37}`。禁用了 SJTUTeX 的固定 20 点基础行距，并在 `\normalsize` 恢复时继续保持校准值。

正文宽为 14.1 cm，小四号全角汉字宽为 12 点，可以容纳 33 个字。测试使用 65 × 33 个连续汉字，实际分为 30、30、5 行，并逐行检查字数与 PDF 字体。段落首行两字缩进占用相应列位；标题、图表、公式、段间留白和末页空白会占用行位，不要求这些页面实际出现 30 行文字。

### 页眉、页脚与封面

`geometry` 同时设置全部版心参数，装订偏移设为零。页眉框高度为 14 点，页眉框顶边距纸顶 2.8 cm；页眉与正文之间的间距由二者位置计算，不能把 `headsep` 单独当作页眉距纸顶的距离。

页码基线距纸底 2.5 cm，对应 `footskip=0.9cm`。这里明确采用“页眉框顶边”和“页码基线”作为位置定义，字形包围框边缘会因字体上伸、下伸和字体度量有所不同。

封面使用独立的版心，完成后恢复正文布局。回归检查在 `\mainmatter` 后再次读取实际参数，确认封面没有改变正文边距、页眉宽度或行距。

### 图表与字体

`setspace` 在浮动体开始时会恢复正文字号，因此不能仅依赖上游声明的五号浮动体字体。现在在该恢复操作之后重新应用五号字体，并显式设置图题、黑体表题及小五号宋体表注。

五号字为 10.5 点；Poppler 的 `pdftohtml` 会将其字体大小四舍五入为 11，因此检查同时验证四个连续汉字的宽度为 42 点，避免将取整后的数字误认为实际字号。

一级标题使用 [`font/方正小标宋简体.ttf`](../font/方正小标宋简体.ttf)，来源为[提供的字体仓库](https://github.com/genqiaolynn/fonts/blob/master/%E6%96%B9%E6%AD%A3%E5%B0%8F%E6%A0%87%E5%AE%8B%E7%AE%80%E4%BD%93.ttf)。字体内部名称为 `FZXiaoBiaoSong-B05S`，PDF 内嵌名称包含 `FZXBSJW--GB1-0`；文件 SHA-256 为 `c52d577dd3aa719ef5fb9ff2043b7f7ca36fae468ef34a47628a3a555d006a49`。

## 复验方法

```bash
make all
python3 -m unittest discover -s tests -v
```

九项检查覆盖 JSON 终稿、JSON 盲审及隐藏外封、`setup.tex` 回退及盲审、封面换行标题与元数据、旧版文档类拒绝、封面后正文版心恢复，以及连续正文行列数和字体字号。编译日志检查还包括未解析引用、缺字、文字溢出及页眉高度警告。正文、标题、图表和封面经过 PDF 页面渲染复核。
